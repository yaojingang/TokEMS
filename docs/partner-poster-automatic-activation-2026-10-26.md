# 合作伙伴海报与分销自动开通迭代

日期：2026-10-26。

大会运营人员可以在伙伴列表直接下载分销海报，或打开宽屏弹窗集中维护资料、头像和海报文案。后台新增伙伴后，分销资格立即生效，伙伴登录个人中心即可使用专属链接。

## 页面与素材

- 列表增加“下载海报”，直接导出最新已保存的 1080 × 1440 PNG。
- 编辑弹窗在桌面采用左侧表单、右侧海报预览，窄屏上下排列；基本资料和海报设置切换时保留草稿。
- 支持上传、替换及移除当前大会的伙伴头像。图片完成上传确认和异步处理后才能保存，失败时保留原头像。
- 邀请语、海报合作介绍、扫码引导标题和扫码说明可编辑，也可恢复默认文案。
- 专属链接可复制，二维码可单独下载。链接和二维码的领取独立于头像处理与海报渲染。
- “保存并下载”先完成原子保存，再导出对应版本；下载前复核状态和版本，变化时提示刷新。

## 分销资格与订单

后台单个或批量新增伙伴时，立即开启资格与推广归因。重复添加已有手机号会打开原伙伴，保留已有资料、佣金比例和管理状态。

立即发布和定时生效规则均更新伙伴的当前规则版本，保留暂停、关闭、独立归因停用及财务冻结状态。管理员主动恢复资格后按当前有效规则生效。本人确认记录保存真实历史，管理员开通记录单独审计。

订单在创建时锁定规则和个人比例。后续规则调整继续保留旧订单的归因快照、佣金及账本记录。

## 权限、隐私与并发

- 头像资产归目标客户，上传、确认、状态读取和新头像绑定校验组织、大会、伙伴及管理员上传来源。
- 读取素材使用读取权限，编辑和上传使用管理权限；图片接口返回私有且禁止缓存的响应头。
- 资料、头像引用、文案和海报展示字段在同一个版本校验事务中保存，保留未提交的联系方式、图库及公开设置。
- 管理字段和版本号来自同一行快照。保存响应锁定本次事务提交的版本，避免并发更新后拿较新的版本号覆盖其他管理员的资料。
- 换伙伴、换大会和关闭弹窗会丢弃旧请求结果。保存期间的新输入继续作为草稿，已保存的头像引用会及时清理出待提交状态。
- 查看与导出素材不会调用推广解析入口，不增加推广访问统计。

## 历史资格与交付

历史升级工具默认生成只读报告，明确追加 `--apply` 才执行转换。正常账号、有效规则和有效链接下的待确认资格可转换；人工限制、财务冻结、失效链接及无法确认历史意图的记录保留原状态，并输出原因。转换保持幂等，审计记录保留原状态及转换后版本。

具体命令、数据边界和回退要求见[合作伙伴与分销功能实现说明](./partner-distribution-implementation.md#历史资格升级)。本轮通过 PR 交付源码，生产发布继续执行仓库的发布流程。

## 验证范围

验证覆盖新增伙伴无需本人确认即可归因计佣、立即与定时规则切换、暂停恢复、重复手机号、订单快照保留、上传归属和处理状态、原子保存、并发版本冲突、历史升级幂等，以及列表下载、二维码解码、头像失败、草稿保护和桌面与窄屏弹窗。

项目检查使用 `pnpm check`，浏览器检查使用 `pnpm test:partner-dialogs` 和 `pnpm test:partner-account`。数据库集成检查使用独立测试数据库，并通过 `PARTNER_TEST_DATABASE_URL` 注入连接，不写入共享预览数据。

交付前在独立工作区通过项目检查及规范快照门禁，数据库验证包含 61 项伙伴 API 测试、7 项 Worker 测试和 2 项历史升级测试；后台弹窗浏览器检查 24 项、个人中心浏览器检查 23 项全部通过。个人中心用例覆盖管理员开通后无需本人确认，以及暂停资格、独立归因停用、失效规则和缺少链接时禁止推广。
