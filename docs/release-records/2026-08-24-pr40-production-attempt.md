## 8. 异常和处理

- 异常：`docker compose build notification-sink api worker web admin gateway` 在构建 Worker 时出现 Docker RPC EOF；Docker 服务随后被系统自动重启。
- 影响：同机 Docker 长期容器全部停止，TokEMS 和 GEOFlow 曾短暂不可用并返回 502。
- 根因：2026-08-24 10:47:08 内核 OOM；内核日志记录 `Out of memory: Killed process 523819 (dockerd)`，当时 `dockerd` 常驻内存约 5.7 GiB。
