## 流程排查

### 登录与大会入口

- [x] 安全 `redirect` 优先恢复原目标页面。
- [x] 当前浏览器的有效最近大会优先于服务端偏好。
- [x] 本地偏好失效、服务端偏好有效时，清理本地记录并进入服务端最近大会。
- [x] 服务端偏好失效、本地偏好有效时，继续使用本地大会并清理服务端记录。
- [x] 唯一进行中、唯一运营中、唯一可用大会可以自动进入。
- [x] 多候选场景进入大会列表，由管理员选择。
- [x] 自动选择只更新运行时上下文，不写最近大会偏好。
- [x] 明确深链接、大会列表选择和切换器选择会更新最近大会。
- [x] 偏好失效提示会保留到目标页面，并描述实际恢复结果。
- [x] 只有管理中心权限的角色进入首个可用管理页面。

### 双层级导航与大会切换

- [x] 大会工作台持续显示当前大会全称、状态、日期和城市。
- [x] 当前大会名称、状态和箭头均属于同一个触发按钮。
- [x] 切换面板可通过点击、Tab、Shift+Tab 和 Escape 操作。
- [x] Escape 关闭后焦点回到切换按钮。
- [x] 点击面板外部可关闭切换器。
- [x] 当前大会使用 `aria-current` 标识。
- [x] 归档大会不参与默认选择，可通过“查看全部大会”访问。
- [x] 管理中心保持一次操作可达，移动端位于导航抽屉中。

### 大会列表与按钮设计

- [x] 生命周期状态与大会名称放在同一信息区。
- [x] “首页默认”只显示一次。
- [x] “进入工作台/继续管理”使用主按钮层级。
- [x] 三个操作时手机端使用两列加一行主操作，两个操作时使用双列。
- [x] “设为首页”禁用时同时提供可见提示和 `aria-describedby` 说明。
- [x] 未公开大会显示“尚未公开”，公开大会才提供“打开”。
- [x] 修改短地址、复制地址和模板设置保持独立动作。

### 响应式与无障碍

- [x] 375px 宽度下页面无横向溢出。
- [x] 提示关闭按钮最小 40 × 40 像素。
- [x] 短地址输入框最小高度 44 像素，手机端字号 16 像素。
- [x] 弹窗居中、操作按钮可见，关闭后焦点恢复。
- [x] 大会切换器支持减少动态效果偏好。
- [x] 桌面端和手机端控制台没有新增错误。

### 安全、权限与数据

- [x] 服务端偏好接口验证成员状态、组织状态、`event.read` 权限和大会归属。
- [x] 跨组织大会返回 404，归档大会返回 409。
- [x] 偏好更新使用原子 JSON 合并，保留其他管理偏好字段。
- [x] 安全回跳拒绝外部地址、双斜杠、反斜杠和未知路由。
- [x] 大会上下文使用一次分组查询，没有逐大会查询。
- [x] 依赖安全审计没有发现已知高风险漏洞。
