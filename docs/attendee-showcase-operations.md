# 报名会员与参会名片运营说明

## 功能范围

本次升级为每条成功报名记录提供一张大会级参会名片。用户可以维护头像、姓名、公司、职位、行业、业务介绍、网址和联系方式，并逐项决定公开范围。

公开名片会进入大会首页的报名会员区块，并生成独立访问地址。用户可在浏览器中生成和下载 1080 × 1440 的个人报名海报。海报二维码会根据名片实时资格指向公开名片或大会主页。

## 发布前准备

1. 备份 PostgreSQL 数据库。
2. 确认 MinIO / S3、Redis 和 Worker 均可用。
3. 执行 `pnpm db:migrate`，确认 `0044_brief_echo` 至 `0046_tricky_multiple_man`
   已全部应用。
4. 部署 API、Worker、Web 和 Admin。
5. 在大会模板中确认存在 `home.members` 和 `flow.member-profile`。
6. 发布大会新版本，使新模板进入当前发布快照。

头像处理复用现有对象存储变量：`S3_ENDPOINT`、`S3_PUBLIC_ENDPOINT`、`S3_ACCESS_KEY`、`S3_SECRET_KEY`、`S3_BUCKET` 和 `S3_REGION`。无需增加外部服务或 API 密钥。

## 运营规则

- 总公开开关初始关闭。
- 电话、邮箱和微信号初始隐藏。
- 姓名和行业填写完整后，用户才能开启公开展示。
- 首页顺序固定使用资格获得时间和报名 ID，后续编辑不会改变位置。
- 公开人数达到 101 人时自动显示行业筛选。
- 每页固定展示 40 人。
- 首页在页面可见时每 8 秒刷新会员目录，重新回到页面时立即刷新；临时请求失败时保留最后一次成功结果并继续重试。
- 部分退款保留展示资格。
- 全额退款、报名取消、票券取消、账号封禁和后台下架会立即停止公开。
- 后台下架需要填写原因；恢复后系统会重新进行资格校验。

## 隐私与安全检查

- 公共列表只返回头像、姓名、公司、职位和行业中的已授权字段。
- 独立名片只返回用户已授权的详情字段。
- 隐藏字段不得进入 JSON、页面 DOM、SEO 描述或海报。
- 业务介绍按纯文本展示。
- 业务网址只接受 HTTP / HTTPS，并使用 `nofollow ugc noopener noreferrer`。
- 公共接口开启频率限制，响应使用 `no-cache, must-revalidate`。
- 头像限制为 5MB 以内的 JPG、PNG 或 WebP。
- Worker 会旋转、裁切为 512 × 512 WebP，并清理图片元数据。
- 过期原图会在 24 小时后进入清理流程。
- 用户更新日志只记录变更字段名、总公开状态和字段授权，不记录联系方式正文。

## 灰度验证

建议先使用内部测试账号完成以下路径：

1. 完成收费报名和支付，确认进入第 5 步。
2. 保存私有草稿，确认首页和公开接口均无记录。
3. 开启公开，确认首页顺序、独立页和海报二维码。
4. 隐藏姓名、头像和联系方式，确认所有公开载体同步脱敏。
5. 编辑资料，确认海报重新生成且首页顺序保持不变。
6. 执行部分退款和全额退款，核对资格变化。
7. 在后台下架并恢复，核对用户端原因提示和公开页面状态。
8. 使用 40、41、100 和 101 条测试记录核对分页与行业分类。

## 回滚

应用版本可以回滚到上一版本。迁移采用加法兼容，回滚应用时保留 `attendee_showcase_profiles` 和 `customer_media_assets` 中的数据。

若需要临时关闭前台展示，可在当前大会模板中关闭 `home.members` 并发布新版本。用户参会名片和授权数据会继续保留，后续重新启用即可恢复资格校验。
