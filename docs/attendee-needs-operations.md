# 参会需求运营与发布说明

## 功能范围

参会者可以为本人名下的有效报名提交 1 至 3 个问题，每题选择 1 至 3 个固定主题标签。新表单默认公开、默认匿名，用户保存公开状态时确认独立授权。大会首页每页读取 10 条有效公开问题，访客手动翻页。

后台按大会管理问题，支持搜索、筛选、正文与标签修改、隐藏、恢复、软删除、恢复管理员删除的问题、匿名化和 CSV 导出。首版通过嘉宾版 CSV 交付问题，不创建嘉宾账号。

## 模板开关

规范大会模板默认开启两个节点：

- `flow.attendee-needs`：报名成功后的第 6 步。
- `home.attendee-needs`：大会首页“会员报名权益”上方的问题模块。

完整发布顺序：

1. 部署数据库迁移、API、Web 和 Admin。
2. 验证用户接口、后台页面和导出。
3. 为 `geo-conference` 组织下的 `tokems26` 大会发布包含两个已启用节点的新版体验快照。
4. 检查首页 0、1、10 和 11 条问题时的模块与分页状态。

关闭任一节点不会删除用户内容。关闭首页节点后，前台停止请求公共问题接口，公共接口本身也返回空分页；关闭流程节点后，用户仍能从个人中心编辑已有内容，新用户不能绕过页面直接创建。

## 权限

| 操作                       | 权限                                                    |
| -------------------------- | ------------------------------------------------------- |
| 查看列表、搜索、筛选和统计 | `event.registration.read`                               |
| 修改正文与标签             | `event.registration.manage`                             |
| 隐藏、恢复、删除和匿名化   | `event.registration.manage`                             |
| 导出嘉宾版或内部版 CSV     | `event.registration.read` + `event.registration.export` |

所有后台操作同时校验当前组织和大会。管理员修改、隐藏、删除或强制匿名时需要填写原因；恢复操作可以补充原因。管理员修改正文或标签后，系统强制匿名并保留审计修订记录。强制匿名在用户再次保存后继续生效。

## 状态说明

| 状态       | 首页               | 用户页面                       | 后台                   |
| ---------- | ------------------ | ------------------------------ | ---------------------- |
| 未提交     | 不展示             | 显示空表单                     | 无记录                 |
| 仅自己可见 | 不展示             | 可编辑、公开或删除             | 显示私有状态           |
| 匿名公开   | 展示“匿名参会者”   | 可编辑授权                     | 显示报名归属           |
| 实名公开   | 展示用户确认的署名 | 可改为匿名                     | 显示署名与报名归属     |
| 资格失效   | 立即停止展示       | 可关闭公开或删除               | 显示资格失效           |
| 后台隐藏   | 对应问题停止展示   | 显示隐藏原因                   | 可恢复                 |
| 后台软删除 | 对应问题停止展示   | 显示移除数量；替代问题进入复核 | 可恢复                 |
| 用户删除   | 停止展示           | 可重新提交新问题               | 保留不可恢复的审计事实 |

公开资格要求大会处于可公开状态、账号正常、报名有效、订单支付成立、电子票有效、报名没有被参会人更换流程取代。全额退款、报名取消、票券失效、账号封禁和参会人更换会立即停止公开展示。

## 编辑与并发

用户和后台保存都携带提交版本。其他页面已经更新时，API 返回 `409`，页面会提示刷新后重试。管理员修改正文或标签后，用户页面显示处理原因。管理员恢复软删除记录时保留原问题排序；若原位置已被新问题占用，系统安排到当前可用位置。

## CSV 导出

- 嘉宾版默认强制匿名，包含问题、标签、公开时间和治理状态。
- 内部版包含报名编号、参会人姓名、用户确认的署名和资格状态，用于运营核对。
- 当前筛选条件会同步应用到导出。
- 单次导出最多 5000 条；超过上限时缩小筛选范围后重试。
- 单次导出按分页读取全部匹配结果，每小时最多 5 次。
- 所有单元格都会处理 `=`, `+`, `-`, `@` 等公式起始字符。

把嘉宾版发送给外部人员前，应保持“强制匿名”开启。内部版只用于有报名管理权限的工作人员，不应上传到公开网盘或群文件。

## 隐私与统计隔离

- 匿名公共响应省略用户 ID、报名 ID、联系方式和署名字段。
- 实名公共响应只包含用户确认的公开署名。
- 问题正文按纯文本保存和渲染。
- 问题正文、标签和署名不进入页面统计事件、服务器业务日志或 SEO 元信息。
- 用户表单位于 `/account` 区域，沿用账号页面的统计脚本隔离规则。
- 从账号页面返回公开大会首页时使用新文档导航，避免敏感页面状态跨区域保留。

## 发布与回退

生产发布遵循 `docs/production-deployment-runbook.md`，发布前创建数据库备份、记录当前提交和容器状态，并为当前镜像添加回滚标签。构建参数和迁移哈希必须完整，常规发布保持 `SEED_DEMO_DATA=false`。

异常处理顺序：

1. 关闭 `home.attendee-needs`，停止首页请求和展示。
2. 关闭 `flow.attendee-needs`，停止报名成功后的流程入口。
3. 保留新增数据表和用户内容，继续调查 API、前端或权限问题。
4. 需要应用回滚时按生产 Runbook 切换到回滚镜像。

回退期间不删除新增表，不覆盖数据库，也不把用户问题导入旧结构。

## 验收清单

- 用户可提交 1 至 3 个问题，每题只能选择 1 至 3 个有效标签。
- 默认公开、默认匿名，实名公开必须提供署名。
- 旧版本保存返回 `409`，不会覆盖管理员或其他页面的更新。
- 跨用户和跨组织访问返回未找到或无权限。
- 多人购票只允许已认领参会者编辑自己的报名需求。
- 退款、取消、失效、封禁和参会人更换后，公共接口立即排除相关问题。
- 首页在 0、1、10、11、20 和 21 条数据下保持正确展示与分页。
- 后台隐藏、恢复、删除、恢复删除和匿名化都有审计记录。
- 嘉宾版默认匿名，内部版权限受控，CSV 公式注入样例已验证。
- 桌面端、移动端、键盘操作、统计隔离和真实浏览器截图通过验收。
