# 根首页与大会顶部导航

## 根首页

在“组织管理 → 公开网站 → 根首页与默认大会”选择展示默认大会或不设置页面。默认业务大会用于未指定大会的历史报名、FAQ 和合作入口。留空首页保留该绑定；默认大会下线前需先切换到另一场已发布大会。

根地址留空时，TokEMS 直接返回 HTTP 200 的极简空白 HTML，GET 与 HEAD 的状态和响应头一致，不加载应用、账户弹窗或统计脚本，并设置 `no-store`、`noindex,nofollow` 和禁止脚本的 CSP。站内进入根地址会创建新文档。旧式 `/?event=tokems26` 继续跳转到独立地址。

独立大会地址 `/tokems26` 和公开默认大会接口 `/api/v1/homepage` 继续有效。后者承担兼容业务上下文及规范导出的数据库身份证明，根页面是否展示不改变该接口语义。

首页设置使用独立的 `GET/PUT /api/v1/admin/organization/homepage`，读取需要 `org.settings.read`，保存需要 `org.settings.manage`。保存携带最新 `revision`；过期版本返回 409。默认大会及展示方式在同一事务内更新。旧 `PUT /api/v1/admin/organization/homepage-event` 继续设置默认大会并开启根首页展示。

## 顶部导航

在“大会 → 基本信息 → 公开页面展示 → 首页展示”编辑顶部导航。每项包含稳定标识、文字、目标、启用状态和打开方式，最多 12 项、每项最多 16 字。支持拖动和键盘可用的上移下移按钮。

- 大会区块：从当前模板选择目标，关闭区块后暂不显示对应链接。
- 大会功能页：自动携带当前大会信息，FAQ 按大会配置进入区块或独立页。
- 自定义链接：站内路径或 HTTP/HTTPS 地址，可含普通查询参数与锚点。拦截脚本协议、协议相对地址、控制字符、反斜杠及含凭据的地址。

未配置 `home.navigation.content.items` 时继承原模板导航及文案。显式空数组隐藏链接区域。恢复默认会回填当前绑定模板的菜单，保存后应用。菜单保存复用首页覆盖和发布快照机制，保留不可变历史版本；冲突会拒绝覆盖并保留编辑内容。

首页、合作页及合作伙伴公共导航共用链接解析与响应式菜单组件。区块链接由稳定区块标识按当前大会短地址生成。手机或桌面空间不足时折叠，支持键盘、Escape 关闭和焦点返回。业务区链接使用完整文档导航。

结构化模板完整支持菜单编辑。HTML 导入模板支持根首页留空，其自带菜单继续通过 HTML 模板维护。

## 同域名其他首页

参考 `docker/root-homepage-coexist.nginx.conf.example`，将根路径精确匹配到其他首页，资源使用 `/site-home-assets/` 独立前缀。大会路径、`/_nuxt/`、`/images/`、API、后台、支付、回调、版本与健康接口保留给 TokEMS。旧式根链接通过受控的命名位置交回 TokEMS 校验和跳转。

示例中的静态目录为 `/www/wwwroot/tokems-site-home`，首页为 `index.html`，资源放在其 `site-home-assets/` 子目录。配置修改前先备份入口配置并运行 `nginx -t`，验收根页、资源、独立大会、旧链接、API 和支付回调路径后再切换。实际页面制作与生产入口接入不属于功能开发的自动操作。

## 规范与回退

规范环境保留 `geo-conference / tokems26` 的默认业务绑定，通过独立大会地址验收页面。完整快照包含 `organization.settings.homepage.mode`，编辑版本号归一化为零；旧快照按原来的大会展示方式兼容。同步模式时保留运行版本号的单调变化，重复同步不重复增加版本。

推送前执行 `pnpm canonical:export`、`pnpm canonical:check`。完整快照及公开派生快照继续执行原有脱敏与数据库身份证明。留空模式不能用来跳过独立大会内容或生产数据验收。

回退旧代码前先恢复根首页展示及旧菜单配置。其他首页已接管根地址时，还需按接入记录恢复入口配置。业务数据和历史发布版本继续保留。
